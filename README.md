هذا المستودع يضم المادة العلمية والتطبيقية لكتاب "Claude: من الصفر إلى الاحتراف". الهدف ليس مجرد نقل النظريات، بل تقديم مسار هندسي متكامل يبدأ من الاستخدام اليومي مروراً بالـ API و Claude Code وانتهاءً ببناء الوكلاء الذكيين (Agents) وتكاملات بروتوكول الـ MCP.

<tr>
<td><b>🎯 1. الأساسيات والنمذجة</b>
<i>(الفصول 1 - 3)</i></td>
<td>
• مقدمة شاملة عن شركة Anthropic وتاريخ تطور عائلات Claude.

• الفروق الجوهرية بين نماذج <code>Haiku</code>، <code>Sonnet</code>، <code>Opus</code>، وفئة <code>Mythos / Fable</code>.

• فهم نافذة السياق (Context Window)، الـ Tokens، والتفكير الممتد (Extended Thinking).
</td>
</tr>
<tr>
<td><b>✍️ 2. هندسة الأوامر</b>
<i>(الفصول 4 - 5)</i></td>
<td>
• تشريح الأمر الفعال (Role, Context, Instructions, Constraints).

• التقنيات المتقدمة مثل Few-shot Prompting وتوظيف علامات الـ XML لفصل السياق.

• آليات المراجعة الذاتية وسلسلة الأوامر (Prompt Chaining).
</td>
</tr>
<tr>
<td><b>💻 3. التطوير والأدوات البرمجية</b>
<i>(الفصول 6 - 9)</i></td>
<td>
• استخدام Claude في هندسة البرمجيات: كتابة الكود، الـ Debugging، وإعادة الهيكلة.

• احتراف أداة الطرفية <code>Claude Code</code> وملفات التوجيه CLAUDE.md.

• التعامل المباشر مع <code>Claude API</code> (باستخدام Python و JavaScript)، البث (Streaming)، والمخرجات المهيكلة.
</td>
</tr>
<tr>
<td><b>⚙️ 4. الوكلاء وبروتوكول MCP</b>
<i>(الفصول 10 - 13)</i></td>
<td>
• تفعيل استخدام الأدوات <code>Tool Use</code> واستدعاء الدوال الخارجية.

• بناء ونشر خوادم <code>Model Context Protocol (MCP)</code> لربط النماذج بقواعد البيانات والخدمات.

• هندسة الوكلاء الذكيين وحلقات العمل (Agent Loops).
</td>
</tr>
<tr>
<td><b>🚀 5. مشاريع تطبيقية واقعية</b>
<i>(الفصول 14 - 20)</i></td>
<td>
• بناء مساعد طرفي لمراجعة الـ Commits محلياً.

• محلل مستندات وفواتير ذكي يعتمد على الـ API.

• مساعد دراسي تفاعلي وتحويل المحاضرات إلى Flashcards.

• نظام تصنيف تذاكر دعم فني هجين (Haiku + Sonnet).
</td>
</tr>
