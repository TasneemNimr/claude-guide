📌 عن المشروع والدليل التقني
يهدف هذا المستودع إلى تقديم مسار تعليمي وهندسي متكامل ومستقل مبني على كتاب "Claude: من الصفر إلى الاحتراف".
التركيز هنا ليس مجرد عرض معلومات نظرية، بل توفير مرجع عملي يساعد المبرمجين، والطلاب، والمطورين على دمج نماذج الذكاء الاصطناعي في مشاريعهم الحقيقية بكل احترافية وسلاسة.
🗺️ خريطة الطريق والرحلة التعليمية (Roadmap)
تتوزع محاور هذا الدليل على عدة مراحل رئيسية مصممة خصيصاً لتدرجك من المستوى الأساسي وحتى الاحتراف:
🎯 1. الأساسيات وعائلات النماذج (الفصول 1 - 3)
 * التعرف بعمق على شركة Anthropic وتاريخ تطور نماذج Claude المتنوعة.
 * الفروق التقنية والدقيقة بين عائلات النماذج مثل Haiku، Sonnet، Opus، وفئة Mythos / Fable لاختيار النموذج الأنسب لمهمتك.
 * فهم مفاهيم نافذة السياق (Context Window)، وحدات النص (Tokens)، استراتيجيات التفكير الممتد (Extended Thinking)، والقدرات متعددة الوسائط.
✍️ 2. هندسة الأوامر المتقدمة (الفصول 4 - 5)
 * تشريح عناصر الأمر الفعال والمثالي (Role, Context, Instructions, Constraints).
 * تطبيق تقنيات Few-shot Prompting وأسلوب الأمثلة الذكية لرفع دقة استجابة النموذج.
 * توظيف علامات الـ XML Tags لهيكلة الأوامر الطويلة وفصل البيانات عن التعليمات بوضوح تם.
💻 3. البرمجة وأدوات التطوير الحديثة (الفصول 6 - 9)
 * توظيف Claude في عمليات هندسة البرمجيات: كتابة الأكواد، مراجعتها، التشخيص (Debugging)، وإعادة الهيكلة (Refactoring).
 * احتراف التعامل مع أداة الطرفية التفاعلية Claude Code (CLI)، وإعداد ملفات التوجيه الدائم للمشاريع CLAUDE.md.
 * الاتصال المباشر بـ Claude API باستخدام لغتي Python و JavaScript، التعامل مع البث اللحظي (Streaming)، والمخرجات المهيكلة (Structured Outputs).
⚙️ 4. الوكلاء الذكيون وبروتوكول MCP (الفصول 10 - 13)
 * تفعيل قدرات استخدام الأدوات وتمرير الدوال الخارجية (Tool Use / Function Calling).
 * بناء واستخدام خوادم Model Context Protocol (MCP) لربط النماذج بقواعد البيانات، الملفات، والخدمات السحابية بسهولة.
 * تصميم حلقات عمل الوكلاء الذكيين (Agent Loops) وإدارتها لإنجاز المهام المعقدة متعددة الخطوات دون تدخل بشري دائم.
🚀 5. مشاريع تطبيقية واقعية وخارطة طريق (الفصول 14 - 20)
تطبيق ما تعلمته عملياً من خلال بناء مشاريع متكاملة:
 * مشروع 1: بناء مساعد طرفي محلي لمراجعة الـ Commits قبل رفعها.
 * مشروع 2: محلل مستندات وفواتير ذكي يعتمد على الـ API واستخراج بصيغة JSON.
 * مشروع 3: مساعد دراسي تفاعلي يحول المحاضرات إلى بطاقات مراجعة (Flashcards).
 * مشروع 4 و 5: نظام ذكي هجين لتصنيف تذاكر الدعم الفني، وربط البنى التحتية عبر خوادم MCP.
