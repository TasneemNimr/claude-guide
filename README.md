# Claude: من الصفر إلى الاحتراف

هذا الكتاب هو مرجع تقني عملي مستقل حول **Claude**، النموذج اللغوي الذي تطوره شركة **Anthropic**، وحول الأدوات المحيطة به (واجهة المحادثة، الـ API، Claude Code، بروتوكول MCP، وبناء الوكلاء الذكيين).

## 📖 عن الكتاب
الهدف من هذا الكتاب ليس تكرار الوثائق الرسمية، بل تقديم مسار تعلم متكامل يبدأ من المفاهيم الأساسية وينتهي بمشاريع حقيقية قابلة للتطبيق.

* **الإصدار:** الأول - أغسطس 2026.
* **إعداد:** تسنيم نمر نصر.
* **ملاحظة:** مرجع تعليمي مستقل - غير صادر عن شركة Anthropic.

## 🎯 الفئات المستهدفة
* المبرمج الذي يريد دمج Claude في سير عمله اليومي.
* طالب هندسة البرمجيات الذي يتعلّم أدوات الذكاء الاصطناعي الحديثة.
* المطوّر المحترف الذي يبني تطبيقات تعتمد على الـ API أو الـ MCP.

## 🛠 محتويات الكتاب
يغطي الكتاب 20 فصلاً تشمل:
1. مقدمة إلى Claude و Anthropic.
2. هندسة الأوامر (Prompt Engineering).
3. البرمجة مع Claude و Claude Code.
4. استخدام الـ API و Tool Use.
5. بروتوكول MCP (Model Context Protocol).
6. بناء الوكلاء الذكيين (AI Agents).
7. مشاريع تطبيقية واقعية وخارطة طريق احترافية.
