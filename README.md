1️⃣ الأساسيات ونماذج Claude
 * ما هو Claude؟ مقدمة عائلات النماذج الكبيرة (LLMs) من شركة Anthropic.
 * عائلات النماذج: التفريق بين استخدامات (Haiku, Sonnet, Opus, وفئة Mythos / Fable) بناءً على السرعة، الاستدلال، والتكلفة.
 * المفاهيم الأساسية: نافذة السياق (Context Window)، وحدات النص (Tokens)، استراتيجيات التفكير الممتد (Extended Thinking)، والقدرات متعددة الوسائط (Multimodal).
2️⃣ الاستخدام التفاعلي وهندسة الأوامر
 * إعداد بيئة العمل: البدء عبر منصة claude.ai واستخدام ميزة Projects لتنظيم السياق والملفات.
 * هندسة الأوامر (Prompt Engineering): عناصر الأمر الجيد (Role, Context, Instructions, Constraints).
 * تقنيات متقدمة: استخدام الأمثلة (Few-shot Prompting)، وعلامات المهيكلة (XML Tags) لزيادة دقة النتائج والمراجعة الذاتية.
3️⃣ الأدوات البرمجية المتقدمة (API & Claude Code)
 * Claude في البرمجة: مراجعة الكود، اختبارات الوحدة (Unit Tests)، وتصحيح الأخطاء (Debugging).
 * Claude Code (CLI): أداة الطرفية التفاعلية للتعامل المباشر مع مستودعات الكود، استخدام ملفات CLAUDE.md، وسير عمل Git.
 * Claude API: إرسال الطلبات برمجياً باستخدام Python و JavaScript، التعامل مع تدفق البيانات (Streaming)، والمخرجات المهيكلة (Structured Outputs).
4️⃣ الوكلاء وبروتوكول (MCP)
 * استخدام الأدوات (Tool Use): ربط النماذج بوظائف خارجية (Function Calling).
 * بروتوكول سياق النموذج (MCP): توحيد اتصال نماذج الذكاء الاصطناعي بمصادر البيانات، قواعد البيانات، وخدمات مثل Slack و Jira.
 * الوكلاء الذكيون (AI Agents): بناء حلقات العمل (Agent Loops)، التخطيط، والذاكرة المهام الآلية المتعددة الخطوات.
5️⃣ مشاريع تطبيقية واقعية
يحتوي الدليل على تطبيقات عملية لتطبيق المهارات المكتسبة:
 * مشروع 1: مساعد برمجي داخل الطرفية لمراجعة الـ Commits محلياً.
 * مشروع 2: محلل مستندات وفواتير يعتمد على الـ API ونظام JSON مهيكل.
 * مشروع 3: مساعد دراسي تفاعلي لتحويل المحاضرات إلى بطاقات مراجعة.
 * مشروع 4: خدمة تصنيف تذاكر دعم فني ذكية (Hybrid Haiku/Sonnet).
 * مشروع 5 و 6: تكاملات عبر بروتوكول MCP وأتمتة سير العمل بالكامل.
